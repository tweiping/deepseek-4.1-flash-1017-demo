# Valley of Ages · 岁月之谷

DeepSeek-V4.1-Flash-1017 官方示例中「Valley of Ages —— 以 3D 场景动态展现从史前时代到现代的发展历程」的一个复刻实现：**一座地形永不改变的山谷，在五个时代里改变它自己的天际线。**

```
deepseek-4.1-flash-1017-demo/
└── valley-of-ages/
    ├── index.html          importmap + 画布 + 地层轨 + 时间轴
    ├── styles.css          设计令牌、布局、焦点态、reduced-motion
    ├── src/
    │   ├── main.js         渲染器、状态机、逐帧混合、相机关键帧
    │   ├── util.js         确定性噪声、色带、程序化贴图、带状网格
    │   ├── ui/timeline.js  时间轴交互、年份插值、地层标记、键盘
    │   └── world/
    │       ├── terrain.js  高度场、土层顶点色、漂砾、渡口坐标
    │       ├── water.js    沿河道带状网格 + flow/fresnel 着色器
    │       ├── sky.js      渐变天球 + 半球光/平行光
    │       ├── palettes.js 五个时代的光照与空气
    │       ├── flora.js    实例化森林（远坡优先）、树桩、树丛
    │       ├── kit.js      基础几何与按时代缓存的材质
    │       ├── bridge.js   四座桥，同一组坐标
    │       ├── effects.js  烟柱与光晕
    │       └── eras.js     五个时代的场景构建
    └── vendor/             three.js r169（本地内置，离线可用）
```

## 运行

需要一个静态服务器（ES 模块 + importmap 不能走 `file://`）：

```bash
cd deepseek-4.1-flash-1017-demo
python3 -m http.server 8080
# 打开 http://localhost:8080/valley-of-ages/
```

任何静态服务器都可以，例如 `npx serve -l 8080 .`。没有构建步骤，没有 npm 依赖 —— three.js 已经放在 `vendor/` 里。

## 操作

| 操作 | 效果 |
|---|---|
| 拖动底部时间轴 | 连续穿越，两个时代之间会互相"生长/沉降" |
| 点击 stone age / iron age / … | 平滑过渡到该时代 |
| `←` `→` | 上一个 / 下一个时代 |
| `1` – `5` | 直接跳到某个时代 |
| `Home` / `End` | 最早 / 现在 |
| `空格` | 播放全程巡游（25 秒走完 11,000 年） |
| `R` 或 recentre 按钮 | 相机回到预设机位 |
| 拖动画面 / 滚轮 | 自由环绕与缩放 |

开启「减弱动态效果」后：没有开场镜头、没有自动巡游，但时间轴照常可用。

## 设计上唯一不能违反的规则

**地形固定，聚落变化。** 这不是五个独立场景，而是一个山谷的五张剖面：

- 河道曲线、山脊、崖顶台地、台地高度、渡口坐标、那块冰川漂砾 —— 全部由 `terrain.js` 里的常量定义，五个时代共用。
- 四座桥（木、石、铁、混凝土）都从 `FORD` 常量读坐标，跨越点永远不会漂移。
- 时间轴左侧的地层轨按**真实年代跨度**分配高度：石器时代占 74%，现代只占 0.4%。深时才是这个作品的真正主题。

每个时代的场景都由 `scale.y` 从台地高度"长出来"，退场时缩回土里 —— 不用透明度交叉淡化，所以没有半透明排序问题，也几乎没有额外性能开销。

## 技术要点

- **确定性**：地形噪声、树木布点、窗格贴图全部用固定种子的 `mulberry32`，每次刷新都是同一座山谷。
- **零外部素材**：烟、光晕、窗格都是 canvas 程序化生成。
- **跨时代植被**：树木按"离村子由远到近"排序，所以减少数量永远等于"近处被砍、远坡留下"，到 2026 年再种回去。
- **性能**：实例化树木/栅栏/光伏板；`pixelRatio` 上限 2；不可见的时代整组跳过更新与绘制；标签页隐藏时停止渲染。
- **无障碍**：时间轴是原生 `range`，带 `aria-valuetext` 与 `aria-live` 播报；键盘可达；焦点环可见。

## 已知取舍

- 视角由关键帧驱动，一旦手动环绕就不再自动接管，只有 recentre / play 会交还控制权。
- 桥只校验不漂移，没有真正的"结构变形"动画 —— 每个时代的桥是独立模型。
